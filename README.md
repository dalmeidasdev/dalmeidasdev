# Olá, eu sou o Diego 👋

Desenvolvo scripts e sistemas para servidores de **FiveM** (Lua, base QB-Core) e bots de Discord. Estou aprendendo programação na prática, criando ferramentas para resolver problemas reais, e documentando o caminho aqui. Moro em Minas Gerais, Brasil.

## 💼 Serviços para servidores FiveM
- Scripts e sistemas sob medida (QB-Core): facções, menus, HUDs e ajustes
- Correção de bugs e adaptação de scripts já existentes
- Bots de Discord integrados ao servidor (whitelist, banimentos e outros)

Combino o escopo antes de começar e entrego por etapas. Para orçamento, me chame no Discord: **zalmeida**

## ⭐ Projeto em destaque
**[alm_hud](https://github.com/dalmeidasdev/alm_hud)**: HUD gratuito para FiveM (QBCore e standalone), com vida, fome, sede, dinheiro, velocímetro e mais. Tudo configurável no `config.lua`, com consumo de 0,03 a 0,04 ms a pé. Feito pela **Almeida Scripts**, com suporte pelo [Discord](https://discord.gg/dfuF2gz8NQ).

## 🛠️ O que já construí
- **HUD para FiveM:** o [alm_hud](https://github.com/dalmeidasdev/alm_hud), publicado com releases, instalação documentada e changelog
- **Servidor FiveM:** uma base própria de servidor, criada com apoio de IA. Eu defini as instruções e as ideias, apliquei tudo e fiz os testes, inclusive dos problemas que a IA não conseguiu resolver.
- **Bots de Discord:** um deles integra com o FiveM para liberar whitelist e aplicar banimentos (feito com apoio de IA).
- **Automações em Python (sem IA):** scripts com `pyautogui` para automatizar tarefas do dia a dia → [automacoes](https://github.com/dalmeidasdev/automacoes)
- **Autocleaner para PC:** ferramenta de limpeza do básico ao avançado, em PowerShell (feita com apoio de IA) → [auto-cleaner](https://github.com/dalmeidasdev/auto-cleaner)
